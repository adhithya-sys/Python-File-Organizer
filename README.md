\# Python File Organizer



A Python automation tool that organizes files into folders based on their file types.



\## Features



\- Automatically detects file types

\- Creates folders based on file categories

\- Moves files into the appropriate folders

\- Helps keep directories clean and organized



\## File Categories



\- Images

\- Videos

\- Documents

\- PDFs

\- Music

\- Archives

\- Other files



\## Requirements



\- Python 3.x

\- No external libraries required



\## How to Run



```bash

python organizer.py
